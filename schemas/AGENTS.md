# Файлы схем

Здесь лежат машинно-проверяемые схемы: JSON Schema для настроек и обмена.
Правила о том, как писать схемы, — в `doc/schemas/`.

## Правила

- Имя файла — по предмету: `httpapi.schema.json`, `health.schema.json`.
- Рядом лежит пример допустимых данных.
- Схема и Go-структура не описывают одни и те же поля независимо: либо
  структура объявляет известные поля, а проверка идёт по схеме, либо структура
  порождается из схемы.
- Пока нет валидатора JSON Schema, загрузчик проверяет обязательные поля
  и запрещает неизвестные ключи; схема описывает ту же форму для человека
  и внешних инструментов. Полный валидатор добавляется вместе с обменом.

## Содержимое

| Файл | Предмет |
|---|---|
| `httpapi.schema.json` | настройки HTTP-службы `config/httpapi.json` |
