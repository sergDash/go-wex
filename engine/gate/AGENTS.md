# Слот ресурса

`engine/gate` — семафор разрешений: ограничивает число одновременных
обращений к одному ресурсу. Нужен там, где ресурс физически один: модель
отвечает по одному запросу, файл нельзя писать двум, порт занят одним
слушателем.

## Что объявляет

- `Gate` — семафор на несколько разрешений.
- `New(n)` — семафор на `n` разрешений; меньше единицы считается единицей.
- `Acquire(ctx)` — взять разрешение, дождавшись места; возвращает функцию
  освобождения, ошибка означает отмену контекста.
- `Capacity`, `Active`, `Peak` — сколько разрешений всего, занято сейчас
  и занимали одновременно.

## Правила

- Разрешение берётся на время работы и освобождается один раз, обычно через
  `defer`. Повторное освобождение ничего не делает.
- Ожидание уважает контекст: отменённый запрос не занимает место.
- Семафор создаёт точка сборки и передаёт зависимостью всем, кто претендует
  на ресурс. Глобальной переменной быть не должно: иначе ограничение
  появится в одном месте, а второй путь к тому же ресурсу — в другом.
- Сколько разрешений нужно, решает приложение, а не движок.
- `Peak` — наблюдение, а не правило: по нему проверяют, что два держателя
  не пересеклись. Значение только растёт.

## Пример

Синхронный ход и фоновая работа ждут одну модель. Оба получают один и тот же
`Gate` с одним разрешением: ход не сталкивается с фоном и не ждёт сам себя.
