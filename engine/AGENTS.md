# Движок

Движок стоит на внутренних службах и работах: HTTP-сервер запускается как
служба, фоновая работа ставится в очередь и разбирается разборщиком.
Остальные пакеты появляются под конкретный сценарий из
`doc/capabilities/scenarios.md`.

`engine/` — граница движка: механизмы, которые не знают предметной области.
Всё, что знает про игру или другой прикладной смысл, лежит в `domains/`.

## Правила

- Пакет движка не импортирует `domains/`. Исключение одно — `engine/app/`:
  это точка сборки, единственное место, где движок знает список модулей.
- Зависимости приходят аргументами, а не из глобальных переменных.
- Механизм не решает, что правильно в предметной области; он даёт средство.
- Каталога `internal` нет: границу держит это правило и `AGENTS.md`,
  а не компилятор.

## Пакеты

| Пакет | Назначение |
|---|---|
| `app/` | точка сборки: настройки, список модулей, службы, сигналы |
| `config/` | настройки из `config/httpapi.json` |
| `core/` | форма модуля и реестр возможностей |
| `service/` | внутренние службы и группа запуска |
| `jobs/` | очередь работ и разборщик |
| `gate/` | семафор разрешений: слот одного ресурса |
| `version/` | версия сборки: подстановка при сборке |
| `events/` | отложенные события: срок, догон, постановка работы |
| `store/` | долговечное хранилище JSON-записей: версия, миграции |
| `clock/` | часы: текущий момент и одно срабатывание |
| `schedule/` | расписание: классы работ, допустимые при простое |
| `activity/` | счётчик активных запросов и метка активности |
| `journal/` | журнал работы: дописывание, ротация |
| `listen/` | слушатели TCP и UDP как службы |
| `process/` | подкоманды и управляемые дочерние процессы |
| `httpapi/` | HTTP-служба, конверт, статика |
