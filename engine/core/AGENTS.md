# Стандарт модуля

Пакет содержит форму модуля и реестр возможностей. Здесь только объявления:
реализации возможностей живут в отдельных пакетах движка.

## Что объявлено

- `Module` — пакет, который подключается к ядру и объявляет возможности.
- `Registry` — то, через что модуль объявляет: HTTP, работы и службы;
  дальше — подкоманды.
- `Handler` — обработчик запроса, возвращающий данные или ошибку.
- `Error` — ошибка с кодом ответа: модуль называет 400, 404 или другой код,
  а не только внутреннюю ошибку 500.

## Правила

- Модуль только объявляет; работу выполняет ядро и обработчики.
- Кодирование ответа — не дело модуля. Код ошибки модуль может назвать
  через `core.Error`, но пишет ответ всё равно `httpapi`.
- Новый вид возможности сначала появляется здесь, потом реализуется
  в пакете движка.
