# Внутренние службы

Движок стоит на внутренних службах: HTTP-сервер, разборщик очереди, слушатели
TCP и UDP, управляемые дочерние процессы — всё это службы с запуском
и остановкой.

## Правила

- `Start` возвращается, когда служба готова принимать работу, и не держит
  вызывающего.
- `Stop` дожидается завершения горутин службы; без этого остановка ядра
  оставляет висящие горутины.
- Группа запускает службы в порядке списка, останавливает в обратном и даёт
  общий срок на остановку.
- Если служба не запустилась, уже запущенные останавливаются, а ошибка
  называет виновника.
- Пауза — необязательная возможность: её объявляет `Pausable`. Группа
  приостанавливает службы в обратном порядке запуска, продолжает в прямом,
  службы без `Pausable` пропускает. Пауза не заменяет `Stop`: порты и файлы
  освобождает только остановка.

## Граница паники

`Guard` оборачивает работу горутины службы: паника превращается
в `PanicError` со стеком. Служба, которая запускает свою горутину, обязана
пропустить её через `Guard` — иначе одна паника завершает процесс.

```go
go func() {
    defer close(done)
    done <- service.Guard(func() error { return s.run(runCtx) })
}()
```

## Надзор

Служба, которая сообщает о конце своей работы, объявляет `Done() <-chan error`.
Канал получает причину и закрывается: `nil` — служба завершилась сама,
ошибка — отказ, в том числе паника. После каждого запуска служба отдаёт
новый канал, иначе второй отказ останется незамеченным.

- Группа ставит наблюдение после каждого запуска и перезапуска.
- Отказ записывается в журнал: обычный — событие `failed`, паника — `panic`
  со стеком.
- Если задано правило `SetRestart(delay, attempts)`, группа ждёт срок,
  останавливает остатки и запускает службу заново; успех пишется событием
  `restart` со счётчиком.
- Без правила служба остаётся отказавшей, а процесс продолжает работу без неё.
  Предел попыток исчерпан — то же самое.
- Перезапуск — это `Stop` и `Start` той же службы, поэтому служба обязана
  уметь начинать заново и не хранить состояние, которое переживает `Stop`.
- Служба, у которой свой перезапуск (`engine/process`), надзору группы
  не нужна: она сама сообщает о своём состоянии.

## Готовность

`Ready() bool` отвечает на вопрос, можно ли давать службе работу. Запуск
и готовность — разные вещи: порт открыт, а модель ещё загружается. Группа
считает готовой службу без этого метода и отдаёт общий ответ через
`Group.Ready`.

## Состояние

`States()` отдаёт службы в порядке запуска: имя, работает ли, готова ли,
сколько перезапусков и причина последнего отказа. По этому списку строится
таблица снаружи; сама служба о списке не знает.
