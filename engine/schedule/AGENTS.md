# Расписание

`engine/schedule` — правило, какие классы работ допустимы при простое.
Расписание — чистая функция от последней активности и текущего момента; оно
не хранит времени и не запускает таймеров. Часы только вызывают проверку.

## Что объявлено

- `Rule` — порог простоя и класс, который после него разрешён.
- `Schedule` — набор порогов, отсортированный по возрастанию.
- `Allowed(lastActive, now)` — классы, чьи пороги пройдены; классы не
  повторяются, момент в будущем даёт нулевой простой.

## Правила

- Пороги — данные: «после десяти секунд — фоновые работы» задаётся
  настройкой, а не кодом.
- Расписание не решает, когда проверять: это делают часы и разборщик.
- Пустой набор классов означает паузу по расписанию; ручная пауза от него
  не зависит.
- Признак занятости (активный запрос) учитывается отдельно: расписание
  отдаёт классы по простою, а разборщик убирает фон, пока запрос активен.
