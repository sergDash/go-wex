# Журнал работы

`engine/journal` — журнал работы движка: дописывание событий в файл,
ротация по размеру, сохранение старых копий. Он нужен, чтобы разбирать сбои,
которые не роняют процесс: повторы, отказы, паники, медленные операции.

## Что объявлено

- `Writer` — приёмник записей: источник, вид, поля.
- `Discard` — отключённый журнал: принимает записи и ничего не делает.
- `Journal` — файл с ротацией; служба с `Start` и `Stop`.
- Запись содержит время, источник, вид и поля; строка — один JSON-объект.

## Правила

- Один писатель: записи сериализуются мьютексом, файл только дописывается.
- Существующий файл при старте не перезаписывается: журнал переживает
  перезапуск.
- Ротация по размеру: текущий файл становится `.1`, прежние сдвигаются,
  старшая копия исчезает. Число копий задаётся настройкой.
- Время берётся у часов, переданных в `New`.
- Ошибку записи журнала некуда вернуть в обработчике паники: вызывающий
  пишет её в обычный журнал процесса.
