# Модуль состояния

Самый маленький пример модуля: объявляет `GET /api/health` и возвращает снимок
состояния сервера. Служит образцом формы, а не местом для новой логики.

## Правила

- Обработчик возвращает структуру, а не пишет JSON вручную.
- Имена полей совпадают с полями стейта в `interface/app.js`.
- Данных и служб модуль не держит.
- `version` в ответе — версия сборки, а не протокола: по ней видно, какой
  код запущен.
- Своих настроек у модуля нет, поэтому любой ключ в его разделе
  `modules.settings.health` — ошибка.
