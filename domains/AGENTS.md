# Модули предметной области

Каждый модуль — отдельный пакет, который реализует форму модуля из
`engine/core` и объявляет свои возможности: маршруты, пункты интерфейса,
слушателей, подкоманды, работы.

## Правила

- Один модуль — одна папка; имя папки совпадает с именем модуля.
- Модуль объявляет, а не запускает: сокеты, службы и горутины принадлежат ядру.
- Модуль не пишет в таблицы другого модуля.
- Модуль не знает о полном списке модулей; список ведёт `engine/app/`.
- Предметные правила, не связанные с транспортом, выносятся в отдельный пакет
  внутри модуля и не импортируют `net/http`.
