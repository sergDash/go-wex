# Настройки HTTP-службы

`httpapi.json` — настройки HTTP-службы: адрес и каталог
интерфейса. Путь по умолчанию — `config/httpapi.json`, переопределяется
флагом `-config`.

## Правила

- Значения проверяются при загрузке: пустое обязательное поле — ошибка.
- Неизвестный ключ — ошибка, а не тихое игнорирование.
- Секретов здесь нет; для них будет отдельный файл с ограниченными правами.
- Схема файла — `schemas/httpapi.schema.json`.

## Файлы

| Файл | Назначение |
|---|---|
| `httpapi.json` | адрес сервера и каталог интерфейса |
