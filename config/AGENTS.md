# Настройки HTTP-службы

`httpapi.json` — настройки приложения: адрес HTTP-службы, каталог интерфейса,
путь к файлу хранилища и пороги простоя для расписания. Путь по умолчанию —
`config/httpapi.json`, переопределяется флагом `-config`.

## Правила

- Значения проверяются при загрузке: пустое обязательное поле — ошибка.
- Неизвестный ключ — ошибка, а не тихое игнорирование.
- Секретов здесь нет; для них будет отдельный файл с ограниченными правами.
- Схема файла — `schemas/httpapi.schema.json` (`$id` версии 3).
- Версия 2 добавила обязательный `store.path`; файл без него не читается.
- Версия 3 добавила необязательный `schedule.rules`. В поставляемом файле
  порог фона — `10s`, чтобы ожидание было видно при запуске; в рабочем
  приложении порог задаётся по нагрузке.
- Миграции настроек пока нет: проектных файлов настроек, кроме поставляемого,
  не существует.
