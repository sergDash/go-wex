# Настройки HTTP-службы

`httpapi.json` — настройки приложения: адрес HTTP-службы, каталог интерфейса,
путь к файлу хранилища, правило хранения очереди и пороги простоя для
расписания. Путь по умолчанию — `config/httpapi.json`, переопределяется
флагом `-config`.

## Правила

- Значения проверяются при загрузке: пустое обязательное поле — ошибка.
- Неизвестный ключ — ошибка, а не тихое игнорирование.
- Секретов здесь нет; для них будет отдельный файл с ограниченными правами.
- Схема файла — `schemas/httpapi.schema.json` (`$id` версии 10).
- Версия 2 добавила обязательный `store.path`; файл без него не читается.
- Версия 3 добавила необязательный `schedule.rules`. Пустой список означает,
  что расписание не ограничивает классы: в поставляемом файле порог простоя
  объявляют сами виды работ (`MinIdle`), а расписание остаётся общим
  выключателем для проектов, которым нужен порог на весь класс.
- Версия 4 добавила необязательный `journal`; без него журнал работы отключён.
- Версия 5 добавила `server.open`, версия 6 — `modules.disabled`.
- Версия 7 добавила необязательный `jobs.keep`: сколько завершённых строк
  очереди держать. Ноль оставляет все.
- Версия 8 добавила пределы транспорта: `readHeaderTimeout`, `idleTimeout`
  и `maxBody`. Пустое значение срока оставляет предел службы по умолчанию;
  отсутствие `maxBody` оставляет предел в один мегабайт, ноль снимает его.
- Версия 9 добавила `services.restart`: срок перед повтором и предел попыток
  для отказавшей службы. Ноль попыток означает, что перезапуска нет.
- Версия 10 добавила `modules.settings`: разделы настроек по имени модуля.
  Форму раздела знает только модуль и разбирает её строго; настройки
  неизвестного или выключенного модуля — ошибка.
- Миграции настроек пока нет: проектных файлов настроек, кроме поставляемого,
  не существует.
