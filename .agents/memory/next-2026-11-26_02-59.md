Что важно знать про wex этой сборки. w-on не передаёт аргументы: обработчик получает событие DOM, значение пункта берут из data-атрибутов. В обработчике w-on/on в this лежит DOM-элемент, а внешняя функция метода вызывается с вью в this — emit отправляют через сохранённую ссылку (var component = this). Хуки $init и $mount у компонентов не вызываются: разбор записан в ~/src/wex-sergDash/Проверить.md для другого агента, возможно баг. Обходной путь в go-wex — подписка на документ при первом открытии списка (WeakSet по состоянию). Поиск внутри компонента держит текст через w-bind и не сбрасывается при повторном открытии: список пересобирается по набранному.
