Проект-скелет go+wex в /home/serg/src/go+wex (каталог позже переименовывается в go-wex, делает пользователь; в go.mod уже module go-wex).

Структура: bin/ в корне для бинарников (в .gitignore); web-server/ — Go-модуль, внутри cmd/app и internal/httpapi; web-interface/ — index.html, app.js, style.less, vendor/; doc/coding (go, wex, css), doc/game; .agents/rules и .agents/memory.

Go 1.27, внешних зависимостей нет. Сервер принимает -addr (по умолчанию 127.0.0.1:8080) и -web; без флага ищет web-interface в текущем каталоге, затем в ../web-interface, проверка по index.html. Статика читается с диска, встроенной копии (embed) больше нет. Запуск: cd web-server && go run ./cmd/app; сборка: cd web-server && go build -o ../bin/app ./cmd/app; из корня ./bin/app.

API отвечает конвертом: успех {"result": ...}, ошибка {"error": "..."}. Сейчас один маршрут GET /api/health. На клиенте ответ разбирается деструктуризацией const { result, error }, error проверяется первым, затем view.update.

Фронтенд: wex-шаблон в index.html, состояние в app.js. В vendor зафиксированы jquery 3.7.1 (не 4.0.0: wex проверен на 3.x), wex коммит 2e7a2f3, less.js 4.6.6. Стили на Less: переменные, миксины surface/row/indicator, изоляция через вложенность, селектор из одного слова; less.js компилирует style.less в браузере.

Документация: книга wex скопирована целиком в doc/coding/wex/book (главы, ai.txt на 2956 строк, html-примеры), api.md рядом. AGENTS.md есть в корне, doc/, doc/coding/, doc/coding/{go,wex,css}/, doc/game/ и web-interface/vendor/.

Правила агента перенесены из глобального окружения в .agents/rules: role, coding_style, engineering_mindset, communication, documentation, memory. Специфика проекта осталась в doc/coding.

Коммиты: 3eacc4b — каркас; a555fcc — документация; 0e92a29 — структура web-server/web-interface, конверт result/error, Less, правила агентов.
