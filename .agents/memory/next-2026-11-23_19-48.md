Демо-модуль domains/demo покрывает возможности примерами: HTTP-маршруты, фоновая работа demo.echo, слушатели TCP и UDP на 127.0.0.1:0, управляемый дочерний процесс `demo child`, подкоманда `demo`, журнал. Адреса слушателей видны в GET /api/demo. Модуль включён в moduleList по умолчанию; порты свободные, настройки не нужны. Подкоманда теперь разбирается до чтения настроек, поэтому `app demo child` работает без файла настроек.

Осталось для полной картины: отложенные события с догоном (SC-10), обновления интерфейса без опроса (SC-16), тексты опыта падений (SC-18). Пул исполнителей и поля времени создания/начала работы ещё не заведены. Миграции store пока не используются (версия 0).
