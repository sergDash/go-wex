Классы работ и захват — план реализации, ещё не сделано. Нужно, чтобы закрыть SC-06 (расписание по простою) и SC-07 (фон не мешает запросу), и чтобы второй вариант паузы заработал.

Job и Spec получают поле Class: interactive и background. Класс задаётся при постановке; если пуст — берётся из Spec вида. MemoryQueue хранит класс в item.

Queue.Claim(ctx, now, allowed []Class): берёт только работы, чей класс есть в allowed. Пустой allowed — не брать ничего, это и есть пауза по расписанию. Порядок выбора: interactive раньше background, внутри класса — AvailableAt, затем ID. Долговечная очередь делает захват одной транзакцией хранилища: выбрать строку, поставить running, записать время начала, увеличить Attempts.

Schedule — чистая функция Allowed(lastActive, now) []Class по порогам из данных, тикер только вызывает. Clock — подставляемые часы (Now, After, Tick), проверки без сна. Оба пакета ещё не созданы.

Проверки: порядок классов; фильтр allowed; пустой allowed не берёт ничего; interactive не ждёт background; повторный захват не берёт running.
