# Правила для агентов

Набор правил, которые действуют в этом репозитории независимо от того,
в каком окружении работает агент. Глобальные настройки машины сюда
не входят: всё нужное для работы с проектом лежит рядом с кодом.

| Файл | Когда читать |
|---|---|
| `role.md` | в начале работы: роль, порядок действий, итерации |
| `coding_style.md` | перед правкой любого кода |
| `engineering_mindset.md` | при выборе решения и оценке компромиссов |
| `communication.md` | при подготовке ответа пользователю |
| `documentation.md` | при создании и правке документации |
| `memory.md` | когда пользователь просит запомнить или найти запомненное |

Правила конкретных слоёв лежат в `doc/coding/*/AGENTS.md`. Они дополняют
эти файлы и не повторяют их.
