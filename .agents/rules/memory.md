# Память

## Где хранится

Память проекта — каталог `.agents/memory/`. Файлы из него доступны агенту
в следующих сессиях. Глобальная память машины сюда не копируется.

## Когда записывать

Когда пользователь просит что-то запомнить, а также когда после решения
остаётся знание, которое понадобится в следующей сессии и которого нет
в документации проекта.

## Имя файла

`ГГГГ-ММ-ДД_ЧЧ-ММ.md`, время берётся командой `date`. Пример:
`2026-11-22_08-30.md`.

Файл, описывающий следующую задачу, получает префикс `next-`:
`next-2026-11-22_08-30.md`. Такой файл читается как план, а не как
запись о прошлом.

## Содержимое

Только запоминаемая информация, без заголовков и служебных полей.
Противоречащая информация из файла с более поздней датой приоритетна.
