# Правила кода проекта

Общие требования к коду — в `.agents/rules/coding_style.md`
и `.agents/rules/engineering_mindset.md`. Здесь — специфика проекта
и карта подразделов.

| Каталог | О чём |
|---|---|
| `go/` | раскладка Go-модуля, формат API, статика |
| `wex/` | библиотека интерфейса, книга, подключение |
| `css/` | Less, вложенность, миксины |

## Что действует во всех слоях

- Данные движутся в одном направлении: домен → JSON → стейт → шаблон.
- Ошибка проверяется до использования результата: `result, err` в Go,
  `const { result, error }` в JS.
- Новая абстракция появляется под конкретную задачу, не «на будущее».
- Комментарий объясняет данные и причину решения, а не синтаксис.

## Документация рядом с правилом

Правило, появившееся в коде, сразу попадает в соответствующий файл этого
каталога. Если правило изменилось, старый текст исправляется в той же
правке.
