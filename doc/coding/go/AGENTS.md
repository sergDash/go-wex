# Go: раскладка и соглашения

## Слои

| Пакет | Что можно | Что нельзя |
|---|---|---|
| `cmd/app` | флаги, выбор источника фронтенда, запуск `http.ListenAndServe` | маршруты, разбор запросов, доменные правила |
| `internal/httpapi` | маршруты, разбор входа, вызов домена, кодирование JSON, коды ответов | игровые правила, работа с файлами мира, вычисления |
| `internal/<домен>` | структуры данных, правила, вычисления, хранение | импорт `net/http`, знание о форме HTTP-запроса |

Доменный пакет не должен знать, откуда пришли данные: из HTTP, из теста или
из консольной команды. Он принимает структуры и возвращает структуры.

## Обработчики

Обработчик состоит из последовательных шагов и не содержит вложенной логики:

1. разобрать вход (метод задан маршрутом, тело и параметры — здесь);
2. проверить вход и вернуть ошибку сразу при неверных данных;
3. вызвать доменную функцию;
4. записать JSON и код ответа.

Ошибки клиенту отдаются в едином виде:

```json
{"error": "что именно не так"}
```

Текст ошибки пишется для человека, читающего интерфейс, а не для разработчика.
Внутренние подробности уходят в журнал через `log.Printf`, а не в ответ.

`r.Context()` передаётся вниз в доменные вызовы, если те делают внешние
операции: запрос к базе, чтение файла, обращение к модели.

## JSON

- Имена полей — `camelCase`, совпадают с полями стейта во фронтенде.
- Структура ответа объявляется рядом с обработчиком; общая структура
  выносится в отдельный файл, если используется несколькими обработчиками.
- Пустой список отдаётся как `[]`, а не `null`: фронтенд перебирает его
  через `w-for` без дополнительных проверок.
- Время — RFC 3339 (`time.Time` кодируется сам).

## Статика

Фронтенд встроен в бинарник через `web/embed.go`. Пакет `httpapi` принимает
`fs.FS` и не знает, откуда взялась файловая система. Это позволяет запускать
сервер с диском (`-web ./web`) без отдельной ветки кода.

## Ошибки и журнал

- `log.Fatalf` допустим только в `main`: после него процесс завершается.
- В библиотечных пакетах ошибка возвращается наверх, а не печатается.
- Ошибку, которую некуда вернуть (например, при записи ответа после
  отправленных заголовков), логируют с указанием операции.

## Имена

- Пакеты — короткие, без подчёркиваний: `httpapi`, `game`, `store`.
- Файлы — по предмету: `health.go`, `chat.go`, `world.go`, а не `utils.go`.
- Тесты — рядом с кодом, `*_test.go`; проверяют поведение домена, а не
  повторяют реализацию.
