# Стили: Less, вложенность, миксины

Исходник стилей — `interface/style.less`. Его компилирует `less.js`
в браузере, поэтому сборщик для CSS не нужен. Подключение: `<link>`
с `rel="stylesheet/less"`, сразу после него — `vendor/less.js`.

## Изоляция через вложенность

Селектор состоит из одного слова. Уникальность задаётся вложенностью:
`.panel .title` существует только внутри `.panel` и не задевает другие
блоки. Длинные имена вида `.panel__title` не используются — область
видна из структуры файла.

```less
.panel {
    .surface();

    .title {
        font-size: 24px;
    }

    .status {
        .row();

        &.ok {
            color: @ok;
        }
    }
}
```

Модификатор состояния — `&.ok` или `&.error` внутри блока. Он компилируется
в `.panel .status.ok`, то есть остаётся изолированным. Классы состояния
ставит `w-class` из шаблона; JS не вызывает `addClass` и не пишет
`element.style`.

## Переменные

Палитра и повторяющиеся значения — переменные Less в начале файла.
Имена по роли, а не по цвету: `@text-muted`, `@ok`, `@error`. В разметке
и JS конкретных цветов нет.

## Миксины

Повторяющиеся наборы свойств собираются в миксины: поверхность карточки,
строка с выравниванием, индикатор состояния. Миксин вызывается внутри
блока и не создаёт отдельного класса в итоговом CSS.

Правило: если одинаковый набор из трёх и более свойств встречается
во втором месте, он выносится в миксин.

## Файлы

Пока весь Less в одном файле: приложение маленькое. Когда появится второй
экран со своим набором стилей, стили экрана переезжают в
`interface/screens/<экран>.less` и подключаются через `@import`.
Общие переменные и миксины остаются в `style.less`.

## Что запрещено

- Inline-стили в разметке (`style="..."`).
- Цвета и размеры числом, если для них есть переменная.
- Селекторы по `#id` для оформления: идентификатор нужен wex для привязки
  шаблона.
- `!important` как способ победить каскад. Если без него не выходит,
  проблема в структуре вложенности.

## Доступность

- Скрытый визуально, но нужный для чтения с экрана текст оформляется
  классом, а не `display: none`.
- Состояние не передаётся только цветом: рядом с цветной точкой остаётся
  текст.
- Размер интерактивной области — не меньше 32×32 пикселя.
