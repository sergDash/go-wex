# CSS: соглашения

## Тема

Цвета, отступы и радиусы задаются переменными в `:root` файла `web/style.css`.
В разметке и JS используются только имена переменных через `var(...)`.
Новый цвет добавляется в `:root` и больше нигде не дублируется.

## Имена классов

Схема — блок, элемент, состояние:

- `.panel` — самостоятельный блок;
- `.panel__title` — элемент блока;
- `.status--ok`, `.status--error` — состояние блока.

Состояние выражается отдельным классом-модификатором, а не вложенным
селектором по структуре. Классы состояния ставит `w-class` из шаблона;
JS не вызывает `addClass` и не пишет `element.style`.

## Файлы

Пока весь CSS лежит в одном `web/style.css`: приложение маленькое, и
разносить три правила по файлам незачем. Когда появится второй экран
со своим набором стилей, стили экрана переезжают в `web/screens/<экран>.css`,
а общие переменные и базовые правила остаются в `style.css`.

## Что запрещено

- Inline-стили в разметке (`style="..."`): они обходят тему и не видны
  при поиске.
- Цвета и размеры, записанные в правиле числом, если для них есть переменная.
- Селекторы по `#id` для оформления: идентификатор нужен wex для привязки
  шаблона, а не как крючок для стилей.
- `!important` как способ победить каскад. Если без него не выходит,
  проблема в структуре классов.

## Доступность

- Скрытый визуально, но нужный для чтения с экрана текст оформляется классом,
  а не `display: none`.
- Состояние не передаётся только цветом: рядом с цветной точкой или полосой
  остаётся текст.
- Размер интерактивной области — не меньше 32×32 пикселя.
