# Возможности движка

Раздел отвечает на вопрос «что движок обязан выдержать». Здесь лежат сценарии:
описания ситуаций и ожидаемого поведения. Это не код, не тесты и не требования
к устройству: реализация свободна, важно только наблюдаемое поведение.

Сценарий — официальная заготовка. Если он описан, его не нужно изобретать
заново; если хочется сделать иначе, это допустимо, но поведение из сценария
должно сохраниться.

## Как писать сценарий

Каждый сценарий имеет номер `SC-NN` и четыре части:

1. **Ситуация** — что происходит и какие данные участвуют.
2. **Ожидаемо** — что можно наблюдать снаружи.
3. **Средства** — какие механизмы движка для этого нужны.
4. **Проверка** — как убедиться, что поведение выполнено.

Правила:

- сценарий описывает наблюдаемое поведение, а не устройство кода;
- если сценарий нельзя проверить, это не сценарий;
- проверка по возможности проходит через панель демо: сценарий, который виден
  в интерфейсе, прогоняется кнопкой, а тест остаётся для того, что кнопкой
  не проверить;
- термины берутся из `doc/coding/engine.md`, свои слова не вводятся;
- сценарий не привязан к предметной области: отчёты и индексация — примеры,
  а не обязательные виды работ.
