# Игровые механики

Раздел для описаний того, что происходит в игре. Здесь нет правил кода:
только устройство мира, данные и переходы состояний.

## Что сюда кладут

- Механики: как устроен ход, что меняется после действия игрока.
- Данные мира: сущности, их поля, связи, где они хранятся.
- Состояния и переходы: из какого состояния в какое и при каком условии.
- То, что видит игрок: какие элементы интерфейса отражают каждое состояние.

## Формат описания

Одна механика — один файл. В начале файла короткий ответ на вопросы: что
делает игрок, что меняется в данных, что он видит после этого. Дальше —
подробности: поля структур, условия переходов, крайние случаи.

Описание механики не должно требовать чтения кода. Если из текста нельзя
понять, какие данные меняются, описание неполное.

## Связь с кодом

Правила кода лежат в `../coding/`. Ссылки на конкретные пакеты и файлы
допустимы, но описание механики первично: код может меняться, правила игры —
нет.

## Перенос из прикладных проектов

Сюда переносятся описания из TNS и подобных проектов: парадигма мира, глоссарий,
устройство глав и сессий. Перенос делается по одной механике, с проверкой,
что описание соответствует текущему коду проекта-источника.
